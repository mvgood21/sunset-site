상대가 안 보여요

선셋톡은 같은 공유기 안에서 서로를 찾아요. 위에서부터 차례로 확인해 주세요.

  1. 같은 Wi-Fi에 연결돼 있나요?

    두 폰의 Wi-Fi 이름이 같아야 해요. 공유기가 2.4GHz와 5GHz 이름을 따로 쓰면 둘 다 같은 이름에 연결해 주세요. 모바일 데이터(LTE·5G)로는 연결되지 않아요.

  2. 두 사람 모두 앱을 열어 두었나요?

    선셋톡은 앱이 열려 있을 때 서로를 찾아요. 둘 다 앱을 열고 목록 화면에서 잠시 기다려 주세요. 상대가 앱을 설치하지 않았다면 보이지 않아요.

  3. 게스트·공용 Wi-Fi는 아닌가요?

    카페, 호텔, 행사장, 회사 게스트 Wi-Fi는 기기끼리 서로를 보지 못하게 막아 둔 경우가 많아요(클라이언트 격리). 이런 곳에서는 앱으로 해결할 수 없어요. 사무실 직원용 Wi-Fi나 집 공유기에서 써 주세요.

    공유기를 직접 관리한다면 관리 화면에서 'AP 격리' 또는 '클라이언트 격리'가 꺼져 있는지 확인해 주세요.

  4. iPhone이라면 로컬 네트워크 권한을 켰나요?

    설정 › 개인정보 보호 및 보안 › 로컬 네트워크에서 선셋톡을 켜 주세요. 처음 실행할 때 권한 요청에서 허용하지 않았다면 여기서 바꿀 수 있어요.

  5. VPN이나 핫스팟을 쓰고 있나요?

    VPN 앱이 켜져 있으면 로컬 네트워크 연결이 막힐 수 있어요. 잠시 끄고 다시 시도해 주세요. iPhone 개인용 핫스팟에서는 지금은 연결되지 않을 수 있어요.

  6. 다시 열어 보세요

    두 앱을 모두 완전히 닫았다가 다시 열거나, 폰의 Wi-Fi를 껐다 켜 보세요.

  7. 그래도 안 되면 알려 주세요

    앱의 설정 › 진단 정보에서 로그를 복사해 {{email:선셋톡 연결 문제}}으로 보내 주세요. 복사한 로그는 IP 주소 일부와 피어 ID 같은 값이 가려진 상태예요.

상대가 맞는지 확인하기(지문)

처음 연결할 때는 같은 Wi-Fi의 다른 기기가 중간에 끼어들지 않았는지 사람이 직접 확인해요. 확인하기 전에는 메시지를 보내지 않아요.

  1. 대화 화면 위의 신원 확인 안내에서 확인하기를 눌러요.
  2. 화면에 내 지문과 상대 지문이 나와요. 4자리씩 네 묶음으로 된 값이에요.
  3. 서로 자기 화면의 '내 지문'을 읽어 주고, 듣는 사람은 자기 화면의 '상대 지문'과 같은지 비교해요. 얼굴을 보거나 전화로 확인하고, 선셋톡 메시지로는 보내지 마세요.
  4. 같으면 확인을 눌러요. 다르면 확인하지 말고 대화를 마치세요.

"보안 키가 변경되었습니다"라는 안내가 나오면 상대가 앱을 다시 설치했거나 데이터를 지웠을 수 있어요. 상대에게 직접 물어보고, 지문을 다시 확인하기 전에는 대화를 이어 가지 마세요.

차단과 신고

  • 모르는 초대: 아는 사람이 아니면 거절하세요. 수락하지 않으면 대화가 시작되지 않아요.
  • 차단: 목록에서 그 사람을 길게 누르고 차단을 골라요. 대화 중에는 화면 위의 더보기 메뉴에서 차단할 수 있어요. 차단한 사람은 목록에 보이지 않고, 그 사람의 초대와 연결은 자동으로 거절돼요.
  • 신고: 목록에서 길게 누르고 신고를 골라요. 신고 내용은 이 폰에만 기록돼요. 저희에게 알리려면 설정 › 신고 안내에서 기록을 복사해 메일로 보내 주세요.
  • 차단 해제: 설정 › 차단한 사용자에서 할 수 있어요.

서버와 계정이 없어서 저희가 특정 사용자를 정지시킬 수는 없어요. 차단이 가장 확실한 방법이에요. 차단은 상대 기기의 신원 키를 기준으로 하므로, 상대가 앱 데이터를 지우고 새로 시작하면 다시 보일 수 있어요. 위험한 상황이라면 경찰(112)에 알려 주세요.

이 폰의 데이터 모두 지우기

  1. 설정 › 모든 데이터 삭제를 눌러요.
  2. 확인하면 프로필, 암호화 키, 대화 기록, 차단 목록, 지문 확인 기록이 이 폰에서 지워져요. 되돌릴 수 없어요.
  3. 처음 화면으로 돌아가요. 다시 시작하면 새 키가 만들어지므로 다른 사람에게는 새로 확인해야 하는 상대로 보여요.
  • 상대 폰에 있는 대화 기록은 지워지지 않아요. 상대가 직접 지워야 해요.
  • iPhone에서 앱을 지울 계획이라면 먼저 이 기능을 실행하세요. 키체인에 저장된 키가 앱을 지운 뒤에도 남을 수 있어요.
  • 저희는 데이터를 보관하지 않아서 대신 지워 드릴 수 없어요. 자세한 내용은 개인정보처리방침에 있어요.

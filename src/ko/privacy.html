선셋톡 개인정보처리방침

이 방침은 SugarMount(개발자 simpest, 이하 "저희")가 배포하는 채팅 앱 선셋톡(영문명 Sunset Talk)에 적용됩니다. 앱이 어떤 정보를 어디에 두고, 누구에게 보이는지 실제 구현을 기준으로 설명합니다.

1. 요약

  • 저희는 선셋톡으로 개인정보를 수집하지 않습니다. 이 앱을 위해 운영하는 서버가 없고, 광고·분석·오류 수집 도구(SDK)를 넣지 않았습니다.
  • 앱이 실행되는 동안 같은 Wi-Fi에 있는 기기들에 닉네임, 아바타, 피어 ID, 내부 IP 주소를 알립니다(2항).
  • 메시지는 대화 상대의 폰으로만 종단간 암호화되어 전달되고, 대화 기록은 대화한 두 폰에만 저장됩니다.
  • 설정의 모든 데이터 삭제로 이 폰의 데이터를 한 번에 지울 수 있습니다.

2. 같은 Wi-Fi에 알리는 정보

선셋톡은 같은 네트워크에서 다른 선셋톡을 찾기 위해 로컬 네트워크 광고(mDNS/DNS-SD, Apple 기기에서는 Bonjour)를 보냅니다. 이 광고는 공유기 밖 인터넷으로 나가지 않지만, 암호화되지 않으므로 같은 네트워크에 연결된 모든 기기가 볼 수 있습니다. 선셋톡이 없는 기기도 네트워크 도구로 볼 수 있습니다.

  • 닉네임(일정 길이까지)과 아바타(목록에서 고른 이모지 1개, 사진이 아닙니다)
  • 피어 ID: 앱이 처음 실행될 때 만든 신원 키에서 계산한 식별자입니다. 전화번호나 계정과 연결되지 않습니다.
  • 이 폰의 내부(사설) IPv4 주소, 대화·초대에 쓰는 포트 번호, 프로토콜 버전

광고는 앱이 실행되는 동안 이어집니다. 위 정보가 다른 사람에게 보이지 않기를 원하면, 신뢰하지 않는 Wi-Fi에서는 앱을 열지 마세요.

3. 대화 상대에게 보내는 정보

아래 정보는 같은 Wi-Fi 안에서 상대 폰으로 직접 전달됩니다. 저희를 거치지 않습니다.

  • 초대: 초대를 보내거나 받을 때 닉네임과 피어 ID가 상대 폰으로 전달됩니다. 상대가 수락해야 대화가 시작됩니다.
  • 연결(핸드셰이크): 닉네임, 피어 ID, 공개키, 무작위 값, 시각, 지원 기능 목록을 주고받아 이 대화에만 쓰는 암호 키를 만듭니다.
  • 메시지: 본문은 종단간 암호화(AES-256-GCM)되어 상대 폰에서만 풀립니다. 메시지 ID, 순번, 보낸 시각, 무결성 확인용 해시, 전달 확인, 입력 중 표시, 연결 유지 신호는 본문과 달리 암호화되지 않으므로, 같은 네트워크에서 통신을 엿보는 사람은 본문은 읽을 수 없어도 이런 정보와 데이터의 크기·시각은 볼 수 있습니다.
  • 다시 연결될 때: 연결이 끊긴 동안 빠진 메시지를 새 연결의 키로 다시 암호화해 주고받습니다.

4. 이 폰에 저장하는 정보

  • 프로필과 키: 닉네임, 아바타, 피어 ID, 신원 키쌍, 대화 상대별 공유 비밀은 Android에서는 Keystore 기반 암호화 저장소에, iPhone에서는 키체인(이 기기 전용, iCloud로 동기화하지 않음)에 저장합니다.
  • 대화 기록: 앱 전용 데이터베이스에 저장합니다. 메시지 본문은 이 폰의 기기 키로 암호화합니다. 상대의 닉네임·공개키, 메시지 시각, 전달 여부 같은 정보는 암호화하지 않은 채 같은 데이터베이스에 둡니다.
  • 설정 기록: 지문 확인 기록, 차단 목록, 신고 기록(최대 100건), 약관 동의 기록은 앱 설정 저장소에 둡니다. 신고 기록은 이 폰에만 있고, 사용자가 직접 메일로 보내지 않는 한 어디에도 전송되지 않습니다.
  • 진단 로그: 최근 로그 500줄을 메모리에만 두며 앱을 끄면 사라집니다. 사용자가 진단 화면에서 직접 복사할 때만 앱 밖으로 나가고, 이때 IP 주소 일부, 피어 ID, 지문 같은 값은 기본으로 가려집니다.
  • 백업: Android에서 앱 데이터는 클라우드 백업과 기기 간 이전에서 제외됩니다.

5. 저희가 받는 정보

  • 앱을 통해서는 없습니다. 저희는 서버, 계정, 분석 도구가 없으므로 사용자의 대화, 닉네임, 대화 상대, 사용 기록을 받지 않습니다.
  • 앱 마켓: 설치와 업데이트는 Google Play와 App Store가 각 회사의 정책에 따라 처리합니다. 저희는 각 마켓이 제공하는 설치 수 같은 집계 통계만 볼 수 있습니다.
  • 메일: {{email}}으로 문의, 신고, 출시 알림 신청을 보내면 메일 주소와 내용을 답장과 요청 처리에만 씁니다. 메일은 Google(Gmail)이 처리합니다. 처리가 끝나면 지체 없이 삭제하고, 출시 알림 신청은 출시 안내를 보낸 뒤 삭제합니다.

6. 권한

Android

  • 인터넷(INTERNET): 같은 Wi-Fi의 상대 폰과 직접 연결하는 데 필요합니다. 인터넷의 서버에는 접속하지 않습니다.
  • 네트워크·Wi-Fi 상태 확인과 변경(ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE, CHANGE_WIFI_STATE): Wi-Fi 연결을 확인하고 로컬 네트워크에서 상대를 찾는 데 씁니다.
  • 근처 Wi-Fi 기기(NEARBY_WIFI_DEVICES, Android 13 이상, 위치 미사용으로 표시)와 위치(ACCESS_FINE_LOCATION, Android 12 이하만): 근거리 Wi-Fi 탐색용으로 선언되어 있습니다. 선셋톡은 위치 정보를 읽거나 저장하지 않습니다.

iPhone

  • 로컬 네트워크: 같은 Wi-Fi의 기기를 찾고 연결하는 데 꼭 필요합니다. 끄면 상대를 찾을 수 없습니다.

연락처, 사진, 카메라, 마이크, 위치 값, 광고 ID에는 접근하지 않습니다.

7. 보관과 삭제

  • 정보는 사용자가 지울 때까지 이 폰에 남습니다. 저희에게는 보관된 정보가 없습니다.
  • 설정 › 모든 데이터 삭제: 프로필, 암호화 키, 대화 기록, 차단 목록, 지문 확인 기록을 이 폰에서 지웁니다.
  • 앱 삭제: Android에서는 앱 데이터가 함께 지워집니다. iPhone에서는 키체인에 저장된 키와 프로필이 앱을 지운 뒤에도 남을 수 있으니, 앱을 지우기 전에 모든 데이터 삭제를 먼저 실행하세요.
  • 상대 폰에 있는 대화 기록은 상대가 지워야 합니다. 저희는 어느 폰의 데이터에도 접근할 수 없어 대신 지워 드릴 수 없습니다.

8. 제3자 제공과 국외 이전

저희는 앱을 통해 정보를 받지 않으므로 제3자에게 제공하거나, 처리를 맡기거나, 국외로 옮기는 정보가 없습니다. 메일 문의는 Google(Gmail)이 처리합니다.

9. 이 웹사이트

sunset.sugarmount21.com은 GitHub Pages로 제공됩니다. 이 사이트는 쿠키, 분석 도구, 외부 글꼴이나 스크립트를 쓰지 않습니다. GitHub는 보안과 서비스 운영을 위해 방문자의 IP 주소 같은 접속 기록을 처리할 수 있습니다(GitHub 개인정보처리방침).

10. 아동

선셋톡은 만 14세 미만 아동을 대상으로 만들지 않았습니다. 저희는 이용자의 개인정보를 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.

11. 이용자의 권리

앱의 정보는 모두 사용자의 폰에 있으므로 앱 안에서 직접 확인하고 지울 수 있습니다. 저희에게 보낸 메일의 열람이나 삭제는 아래 이메일로 요청해 주세요.
